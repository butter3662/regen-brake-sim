브레이크 회생발전 시뮬레이터

자동차가 제동할 때 바퀴와 함께 도는 쇳조각이 차체에 고정한 전자석 철심의 틈을 지나가며 자속을 바꾸고, 철심에 감은 코일에 전기가 유도된다. 계자 전류, 속력, 코일 조건에 따라 발전량이 얼마나 달라지는지 계산한다. 입력값은 모두 예시(가정)값이다.

기본 모드: 계자 전류, 속력, 코일 조건에 따라 발전량이 어떻게 달라지는지 본다.

쇳조각이 지나갈 때 전류와 자속이 바뀌는 과정

펼친 원판 둘레를 위에서 본 그림이다. 쇳조각(회색)은 ← 방향으로 이동하고, 철심마다 코일 1개(초록)가 있다. 정렬 직전 +48 V(여자) → 멀어지는 동안 전류 유지(발전) → −48 V(회수). 자속(빨간 점선)은 전류가 흐를 때만 생긴다. B는 A보다 1.5칸 뒤라 번갈아 일한다. 그림은 100배 느리게, 그래프는 실제 속력 기준이다.

단계별 원리

  1. 회전 전달. 쇳조각 원판은 바퀴 허브에 붙어 바퀴와 같은 각속도로 돈다. 기어는 없다. 바퀴는 미끄러지지 않고 구르므로 바퀴 각속도와 쇳조각이 철심 앞을 지나가는 빈도는 다음과 같다.
    ωw = v / rw,    f = Z ωw / 2π
  2. 자기 회로와 인덕턴스. 자속 경로: 철심 → 틈 → 쇳조각 → 틈 → 철심, 자기 저항은 공기 틈이 대부분. 틈 합: 쇳조각 있음 g = 2 mm, 없음 g + t = 18 mm → 인덕턴스가 각도 θ에 따라 변한다.
    L(θ) = Na2 [𝒫off + (𝒫on − 𝒫off) × 겹침(θ)],    𝒫on = μ0A/g,    𝒫off = μ0A/(g+t),    Φ = Na 𝒫 i
    𝒫: 퍼미언스(자속이 지나가기 쉬운 정도), A: 다리 끝 단면적, 겹침: 0~1. 기본값(16회, h = 65 mm): Lon ≈ 0.41 mH, Loff ≈ 0.045 mH. 전류 상한 Iref = min(Isat, 150 A), Isat = Bsatg/(μ0Na) ≈ 149 A(포화 1.5 T 가정).
  3. 전압식과 에너지.
    v = R i + d(L i)/dt = R i + L di/dt + i ω dL/dθ
    v i = R i2 + d(½L i2)/dt + T ω,    T = ½ i2 dL/dθ
    v: 코일 전압, R: 코일 저항, ω: 원판 각속도, T: 전자기 토크. 항별: vi 배터리와 오가는 전력 · Ri2 저항 열 · ½Li2 자기장 저장 에너지 · Tω 기계 일률. 다가옴(dL/dθ > 0) + 전류 → T > 0, 모터(손해). 멀어짐(dL/dθ < 0) + 전류 → T < 0, 제동 → 운동에너지 −Tω가 전기로. T ∝ i2 → 전류 방향 무관, 단방향 회로로 충분.
  4. 스위칭 한 주기. 철심마다 스위치 2 + 다이오드 2(비대칭 하프브리지). 쇳조각 하나마다 반복:
    1. 여자 (켜는 각도 θon, 정렬 직전): +48 V → 전류 상승(di/dt ≈ V/L), 배터리가 Ein을 빌려줌. 정렬 근처라 dL/dθ ≈ 0 → 모터 손해 작음.
    2. 발전 (정렬 뒤): 쇳조각이 멀어지며 dL/dθ < 0이 된다. 변환기는 +48 V와 −48 V를 번갈아 걸어 전류를 Iref 근처로 유지하고, 이 동안 제동 토크가 생긴다.
    3. 회수 (끄는 각도 θoff): 두 스위치를 끈다. 코일 전류는 끊기지 않고 다이오드 두 개를 거쳐 배터리 + 쪽으로 밀려 들어가며, 코일에는 −48 V가 걸려 전류가 0까지 줄어든다. 다음 쇳조각이 다가오기 전에 0이 되어야 모터 구간을 피한다.
    Eout − Ein = Wmech − Ecu > 0
    Eout은 배터리가 돌려받은 에너지, Wmech는 바퀴에서 빼앗은 기계 일, Ecu는 코일 저항 열이다. 여자 에너지는 쓰고 버리는 것이 아니라 빌려주는 것이고, 바퀴의 일만큼 더 돌아온다. 시뮬레이터는 속력마다 θon, θoff 조합을 여러 개 계산해 순 생산이 가장 큰 것을 고른다.
  5. 제동력. 철심 n개의 평균 기계 전력 Pm은 운동에너지에서 나온다:
    Fgen = Pm / v
    T ∝ i2, 전류는 Iref에서 제한 → 기본값 최대 약 180 N(마찰 5100 N보다 훨씬 작음). 약 5 km/h 아래: 여자 에너지를 다 못 돌려받음 → 변환기 쉬고 마찰만. 전류가 0이면 당김 없음 → 평소 주행 방해 없음.

비교용: 계자 코일 + 다이오드 방식

시뮬레이션 탭에서 ‘다이오드 정류 + 계자 코일’을 고르면 이 방식으로 계산한다(위 그림도 전환). 같은 철심·원판에 철심마다 계자 코일(직류 전자석) + 발전 코일을 감는다. 장점: 스위치 없이 정류기만. 단점: 계자 전력(약 800 W)이 계속 열로 손실, 인덕턴스 때문에 전류가 늦게 자람 → 순 생산이 전력 변환기 방식의 절반 이하.

  1. 자기 회로. 자속 경로 철심 → 틈 → 쇳조각 → 틈 → 철심, 자기 저항은 공기 틈이 대부분. 틈 합: g = 2 mm(쇳조각 있음), g + t = 18 mm(없음).
    Φon = μ0 Nf If A / g,    Φoff = μ0 Nf If A / (g + t),    ΔΦ = Φon − Φoff
    포화 시 Φon = BsatA에서 멈춤(Bsat = 1.5 T 가정).
  2. 전자기유도 (패러데이 법칙). θh = π/Z(15°) 동안 겹침 0 → 최대, 자속 ∝ 겹친 면적 → |dΦ/dt| = ΔΦ ωw/θh로 일정. A·B는 반대로 변함 → A 정방향·B 역방향 직렬(짝 n/2개)이면 기전력이 더해진다.
    ε = −Na d(ΦA − ΦB)/dt × (n/2)  ⇒  |ε| = n Na ΔΦ ωw / θh = K v,    K = n Na ΔΦ / (θh rw)
    계자 코일은 ΦA + ΦB(일정)를 느껴 기전력 없음.
  3. 전류와 전력. 발전 코일 n개(저항 r, 인덕턴스 L) + 부하 R 직렬 = 네모파 기전력 Kv가 걸린 RL 회로. 빠를수록 전류가 다 자라기 전에 방향이 바뀐다. 한 주기 평균 전력:
    P = (K v)2 / (R+r) × (1 − tanh x / x),    x = (R+r) / (4 L f),    L = (n/2) Na2 μ0 A (1/g + 1/(g+t))
    느릴 때(x 큼): 괄호 ≈ 1(인덕턴스 무시와 같음). 빠를 때(x 작음): 괄호 ≈ x2/3 → P가 상한에 접근. 부하 몫 PL = R/(R+r) × P. 정류기 다이오드 손실 무시.
  4. 렌츠 법칙에 의한 제동. 유도전류 → 자속 변화를 방해 → 쇳조각 움직임을 방해하는 힘. 전력 P는 운동에너지에서 나온다:
    Fgen = P / v
    거의 멈추면 Fgen → 0(마찰이 대부분 담당), 아주 빠르면 전력 상한 때문에 Fgen 감소. 발전 전류가 없으면 A·B 당김이 상쇄 → 주행 방해 없음.

운동에너지는 어디로 가는가

시뮬레이션 탭의 현재 값으로 계산한 에너지 분배이다. 마찰 브레이크가 열로 바꾼 몫을 빼고 남은 에너지가 전기가 되고, 그중 일부는 코일 저항에서 열로 사라진다.

최종 설계안(쇳조각 원판 + 고정 U자 철심)의 3D 모형이다. 화면을 끌어서 돌려 보고, 두 손가락이나 마우스 휠로 확대한다. ‘U자 철심 확대’를 누르면 철심 하나의 구조와 자속 경로를 가까이서 본다. ‘작동 과정 보기’는 전력 변환기 방식에서 쇳조각 하나가 지나갈 때 일어나는 일(켜기 → 붙잡기 → 끄기)을 회로와 함께 느리게 보여 준다.

계산 조건

마찰 브레이크는 제동 시작부터 정지까지 시뮬레이션 탭에서 정한 힘 Ffr로 일정하게 작동하고, 발전기 제동력은 여기에 더해진다(예: 1500 kg에 5100 N이면 마찰만으로 3.4 m/s² 감속). 공기저항과 구름저항은 무시한다.

발전기 구조: 바퀴 허브의 비자성 원판 + 쇳조각 Z = 12개(폭 39 mm, 두께 16 mm, 반지름 0.125 m부터 h)가 차체에 고정한 U자 철심 n개의 두 다리 사이를 지난다. 다리 끝 단면적 A = 39 mm × h, 다리·등 두께도 h(틈과 철심이 함께 포화). 규소강판 적층(철손 무시). 틈 합: g = 2 mm(1 mm × 2), 쇳조각이 없으면 g + t = 18 mm(t: 쇳조각 두께). 기어 없음, 타이어 반지름 0.33 m.

철심 배치: A는 30° 간격, B는 A에서 45° 떨어진 곳부터 30° 간격 → 차지하는 각 S = 30°(n − 2) + 45°(맨 위 중심). 바깥 반지름 rout = 0.185 m + 2h. 조건: ① rout ≤ 타이어 반지름 − 1 cm(휠 안), ② 가장 아래 철심이 지면에서 0.10 m 이상(가정). 12개는 A·B 간격이 15°라 부딪혀 최대 10개. 벗어나면 변수 칸에 경고.

코일 (다이오드 방식): 철심마다 계자 코일·발전 코일 1개씩, 종류별 직렬. 한 바퀴 길이 l = 2(39 mm + h) + 50 mm(기본 0.258 m). 각 코일 구리 단면적 합 250 mm²(공간 약 500 mm², 채움률 0.5 가정) → 저항 ∝ 감은 수². 계자: Rf = ρl Nf2/Acu(철심 1개), 전체 nRf, 전원 48 V 배터리. 전력 변환기 방식의 코일은 아래 ‘전력 변환기 방식 계산’ 참고.

부하: 정류기 뒤의 48 V 배터리 충전 회로를 저항 R = 0.77 Ω 하나로 근사했다(가정). 철심: 포화 자기장 1.5 T(가정)이고, 철의 자기 저항, 틈 가장자리로 새는 자속, 철손(와전류·히스테리시스)은 무시한다.

기본값의 근거

페이지를 처음 열거나 ‘기본값으로 되돌리기’를 누를 때 들어가는 값이다. 실제 자료가 있는 값은 출처를 적었고, 자료가 없는 발전기 설계값은 가정임을 밝혔다.

시뮬레이션 화면 읽는 법

주행 애니메이션

누적 에너지: 사용 = 전자석(또는 코일 여자) 에너지, 순 생산 = 발전 − 사용, 손실 = 마찰 열 + 코일 저항 열, 회수 효율 = 순 생산 ÷ 손실(분모가 손실이라 100% 초과 가능). 휴대폰 배터리 환산: mAh = E[J] ÷ 3.85 V ÷ 3.6 (1 mAh = 3.6 C, 48 V 기준이면 약 1/12). 재생: 실제 시간 비율, 값을 바꾸면 처음부터, 막대를 끝으로 옮기면 제동 전체 값. 그림: 화살표 = 마찰(주황)·발전기(파랑) 제동력, 전선 점선 속도 = 전류 크기, 배터리 칸 = 최종 대비 누적 비율, 회색 점선 차 = 마찰만으로 서는 차.

그래프

  • 계자 전류와 에너지: 다른 값은 그대로 두고 계자 전류 If만 바꾼 결과이다. 철심이 포화되기 전에는 발전량과 전자석 소비가 모두 If2에 비례해 함께 커진다. 포화 뒤에는 자기장이 더 커지지 않아 발전량은 그대로인데 소비만 늘어 순이득이 줄어든다.
  • 제동 시작 속력과 발전량: v0만 바꾼 결과. 느릴 때 ∝ v03(전력 ∝ v2, 제동 시간 ∝ v), 빠를 때는 인덕턴스로 전력이 상한에 다가가 대략 ∝ v0.

계산 방법

1. 운동 방정식

m dv/dt = −(Ffr + Fgen),    Ffr = 일정,    Fgen = P(v) / v
P(v) = (K v)2 / (R+r) × (1 − tanh x / x),    K = n Na ΔΦ / (θh rw),    x = (R+r) / (4 L f),    f = Z v / (2π rw)

θh = π/Z 동안 겹침 0 → 최대, 자속 ∝ 겹친 면적 → 철심 하나의 |dΦ/dt| = ΔΦ ωw/θh로 일정 → A·B를 반대로 이은 n개의 기전력은 크기 Kv의 네모파. 이 기전력이 R+r, L 회로에 걸리면: 반주기 h = 1/(2f), 시간상수 τ = L/(R+r), 반주기 끝 전류 Ip = Kv/(R+r) × tanh(h/2τ) → 한 주기 평균이 위의 P(v)(x = h/2τ). Fgen = P/v(렌츠 법칙). A·B 겹침 합 = 1 → L은 위치와 무관하게 일정.

2. 정지 시간과 정지 거리 (수치 적분)

T = ∫ m dv / (Ffr + Fgen(v)),    xs = ∫ m v dv / (Ffr + Fgen(v))    (v: 0 → v0)

Fgen이 속력에 단순 비례하지 않아 해를 식 하나로 쓸 수 없으므로, 속력을 400칸으로 나눠 사다리꼴 공식으로 적분한다. 발전기가 없으면 xs = v02/(2af)가 된다.

3. 발전량 (에너지 보존)

E = R/(R+r) × ∫ P dt = R/(R+r) × (½ m v02 − Ffr xs)

전기에너지 = 처음 운동에너지 − 마찰 열(Ffrxs)(전자석을 중간에 끄면 그때까지). 그중 R/(R+r)는 부하, 나머지는 코일 열. 인덕턴스 영향이 작고(x ≫ 1) 발전기 힘 ≪ 마찰일 때 근사:

E ≈ R/(R+r)2 × K2 × v03 / (3af)

빠를 때(x ≪ 1)는 전력이 속력과 상관없는 상한에 다가간다.

P∞ = (R+r) ΔΦ2 / (3 Na2 (𝒫on + 𝒫off)2),    𝒫on = μ0A/g,    𝒫off = μ0A/(g+t)

경향: Na ↑ → 느릴 때 전력(K2 ∝ Na2) ↑, 빠를 때 상한 ↓ → 최적 감은 수가 있다. 포화 전 계자 전류 × 2 → ΔΦ × 2 → 전력 × 4. Ffr ↑ → 빨리 서서 발전 시간 ↓. Ffr = 0이면 완전히 서지 않으므로 처음 속력의 1%를 정지로 본다. E ∝ m(t = mτ로 바꾸면 m이 사라짐). 상한: E ≤ R/(R+r) × ½mv02.

전력 변환기 방식 계산

‘전력 변환기’를 고르면 계자 코일 없이 철심마다 코일 1개를 비대칭 하프브리지로 따로 제어한다(스위치드 릴럭턴스 발전기). 계자 자리까지 감음 → 구리 단면적 500 mm², 두께 몫 2배 → l = 2(39 mm + h) + 100 mm → 같은 감은 수에서 저항 약 0.6배. 철심 간 상호 인덕턴스는 무시하고 철심 1개 결과 × n.

1. 코일 하나의 전압식

v = R i + L(θ) di/dt + i ω dL/dθ,    L(θ) = Na2 (𝒫off + (𝒫on − 𝒫off) × 겹침)

한 칸(30°) 동안 겹침 0 → 1 → 0(직선), L: Loff → Lon → Loff. 멀어질 때 dL/dθ < 0 → 마지막 항이 발전 기전력, 제동 토크 T = ½i2 |dL/dθ|.

2. 스위칭 방법

① 켬(uon ~ uoff): i < Iref면 +V, 넘으면 −V → Iref 근처 유지. ② 끔(uoff 이후): −V로 0까지 배터리에 반환. 한 칸을 240등분해 수치 적분: 배터리 에너지 Eb = ∫(−v)i dt, 코일 열 Ecu = ∫Ri2 dt, 바퀴에서 빼앗은 에너지 = 둘의 합. 각도 후보 uon = 0.35·0.45·0.5칸, uoff = 0.7·0.85·0.94·0.98칸(정렬 = 0.5칸) 중 속력마다 Eb 최대를 고른다. 모두 Eb ≤ 0이면 쉰다.

Pb(v) = n fs Eb,    Fgen(v) = n fs (Eb + Ecu) / v,    fs = Z v / (2π rw)

3. 전류 상한

Iref = min( Bsat g / (μ0 Na), Imax )

앞쪽: 정렬 시 틈이 포화(1.5 T)되는 전류. Imax: 스위치·배선 한계(변수 칸에서 조절, 기본 149.2 A = 감은 수 16회의 포화 전류). 감은 수 ↓ → 포화 전류 ↑지만 150 A에서 막힘 → 최적 약 16회. 공간이 고정이면 R ∝ Na2, Isat ∝ 1/Na → 코일 열 RI2은 감은 수와 거의 무관.

1. 전자석이 만드는 자기장

철심 1개 + 계자 코일 + 공기 틈 자기 회로에 앙페르 법칙 적용. 철의 투자율이 매우 커서 자기 저항은 공기 틈이 대부분. B: 쇳조각이 틈을 메웠을 때 틈의 자기장, 1.5 T에서 포화(가정).

2. 전자석이 쓰는 에너지

Pf = n If2 Rf,    Ef = Pf ton
Rf = ρ l Nf2 / Acu  ⇒  Pf = (n ρ l / Acu) (Nf If)2,    Vf = n If Rf

계자 코일 n개 직렬: 같은 If, 전체 저항 nRf. 공간이 고정 → Rf ∝ Nf2 → 소비 전력은 기자력 NfIf만으로 결정(감은 수와 무관). 감은 수 ↑ → 전류 ↓, 전원 전압 Vf ∝ Nf ↑(48 V 넘으면 경고). 자기장 유지에는 일이 들지 않으므로 소비 = 코일 저항 열뿐(처음 저장 에너지는 무시). 발전 에너지의 출처는 전자석이 아니라 차의 운동에너지.

3. 손익분기 속력

R/(R+r) × P(vbe) = Pf

부하 몫 R/(R+r) × P(v)가 Pf보다 작아지는 속력 vbe 아래에선 손해 → 전자석을 끄고 마찰만. P(v)는 속력에 따라 증가 → 이분법으로 vbe를 찾는다. 상한 P∞ < Pf면 항상 손해 → 켜지 않음. 포화 전 P ∝ If2, Pf ∝ If2 → vbe는 계자 전류와 무관하고 구조(Rf, Nf, Na, n, h, g, Z 등)로 정해진다.

같은 상수 k가 두 식에 함께 쓰이는 근거는 에너지 보존이다. 제동 토크가 빼앗는 기계적 일률 τgωg = kIωg = εI가 회로가 받는 전기적 일률과 같아야 하기 때문이다. 이 전력 중 I2R은 부하로, I2r은 코일 발열로 간다. 실차 모형에서 전류 상한 Imax를 두면 I = min(ε/(R+r), Imax)이고, 이때 부하 전력은 PL = εI − I2r로 계산한다. 이는 제어기가 부하를 조절해 전류를 상한에 맞춘다는 가정이다.

2. 실험 모형: 회전 원판

J

M, a
원판의 질량 (kg), 반지름 (m)
ω
원판 각속도 (rad/s). 발전기 축에 직결하므로 ωg = ω이다. 회전수 n(rpm)과는 ω = 2πn/60의 관계이다.
τf
베어링 등의 쿨롱 마찰 토크 (N·m). 속도와 무관한 일정값으로 둔다.
b
점성 마찰 계수 (N·m·s/rad). 공기 저항 등 속도에 비례하는 손실을 나타낸다.

초기 회전 운동에너지 (J)

마찰이 전혀 없으면(τf = b = 0) 같은 전류가 R과 r을 직렬로 흐르므로, 원판이 멈출 때까지 회수되는 비율은 R/(R+r)로 정확히 정해진다. 마찰이 있으면 R을 키울수록 전기적 제동이 약해져 마찰이 더 많은 에너지를 가져가므로, 회수 에너지가 최대가 되는 R이 존재한다. 위의 세 번째 그래프가 그 최적값을 수치로 찾는다.

4. 실험에서 입력값을 구하는 방법

  • k: 발전기(예: 소형 DC 모터)를 일정 회전수로 돌리며 부하 없이 단자 전압 Voc를 재고, k = Voc / ω로 구한다. 여러 회전수에서 측정해 기울기로 구하면 더 정확하다.
  • r: 멀티미터로 발전기 단자 저항을 재거나, 부하를 연결했을 때 단자 전압 V = ε − Ir의 관계에서 구한다.
  • τf, b: 회로를 연 상태에서 원판의 감속 곡선 ω(t)를 측정하고, 이 시뮬레이터의 ‘개방 회로’ 곡선이 측정값과 겹치도록 맞춘다.

5. 실제 차량에 쓰이는 비슷한 기술

  • 마쓰다 i-ELOOP: 12~25 V 가변전압 교류발전기, 전기이중층 커패시터, DC/DC 컨버터로 감속 시 발전한다. 제조사는 정체 구간 연비가 약 10% 개선된다고 발표했다. (The Engineer)
  • BMW Brake Energy Regeneration: 가속 중에는 발전기를 분리하고 감속·제동 때 주로 발전한다. 제조사 설명 기준 연비 개선은 최대 3%이다. (Autobytel)
  • 48 V 마일드 하이브리드: 교류발전기 자리에 벨트 구동 시동발전기를 넣는다. 현대 i30는 제동 시 최대 10~12 kW를 회수한다고 밝히고 있다. (Hyundai, Valeo)
  • 와전류 리타더: 버스·트럭에서 전자기유도로 제동하지만 에너지는 열로 버린다. 제동 보조만 하고 발전은 하지 않는 사례이다. (Telma)
