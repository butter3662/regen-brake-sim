# 브레이크 회생발전 시뮬레이터

내연기관 자동차의 제동 에너지를 전자기유도로 회수하는 과정을 계산하는 웹 시뮬레이터이다. 에너지 하베스팅 자율탐구용으로 만들었다.

## 기능

- **기본 모드**: 최종 설계안인 쇳조각 원판 구조(유도자형 교류발전기)로 계산한다. 바퀴와 함께 도는 쇳조각 12개가 차체에 고정한 U자 철심 4개(A, B, A, B)의 틈을 메웠다 비웠다 하며 자속을 바꾸고, 발전 코일에 네모파 기전력이 생긴다. 제동 시작 속력 *v*<sub>0</sub>, 차량 질량 *m*, 마찰 브레이크 제동력 *F*<sub>fr</sub>(0부터), 발전 코일 감은 수 *N*<sub>a</sub>, 계자 전류·감은 수·저항을 바꾸며 제동 중 발전량, 정지 거리, 전자석 소비 전력, 순이득, 손익분기 속력을 계산한다. 발전 코일의 저항과 인덕턴스는 감은 수로 계산하고, 인덕턴스 때문에 빠를수록 전력이 상한에 다가가는 효과(RL 회로의 네모파 평균 전력)를 포함한다. 운동 방정식은 수치 적분으로 푼다. 마찰 브레이크와 전자기유도 제동이 제동 시작부터 함께 작동하고, 입력값에 따라 자동차 주행 애니메이션이 바뀐다.
- **작동 원리 탭**: 흐름도, 쇳조각이 철심 A·B 사이를 지나가는 펼친 그림과 자속·기전력 그래프 애니메이션, 단계별 원리를 보여 준다.
- **3D 모형 탭**: 최종 설계안(쇳조각 원판 + 고정 U자 철심 4개)을 깊이 버퍼 방식의 자체 3D 렌더러로 보여 준다. 끌어서 회전, 휠·두 손가락으로 확대하고, ‘U자 철심 확대’ 시점에서 철심 하나의 구조와 자속 경로를 본다. 철심 A·B의 자속, 발전 기전력, 자속 변화 빈도를 함께 표시한다.
- **세부 내용 탭**: 계산 조건, 기본값의 근거, 화면 읽는 법, 계산 방법(인덕턴스 포함)과 전자석 계산 공식, 장치 구성도, 회로도, 부품표를 모아 둔다.
- **고급 모드** (스위치로 켜고 끔): 아래 세 기능을 포함한다.
  - **실험 모형 (회전 원판)**: 소형 발전기를 회전 원판에 연결했을 때 회전수 변화, 부하 전력, 에너지 분배를 계산하고, 부하 저항 *R*에 따른 회수 에너지 곡선에서 최적값을 찾는다.
  - **실차 모형 (내연기관차)**: 별도 발전기를 장착한 차량이 목표 감속도로 정지할 때 발전기와 마찰 브레이크의 제동력 분담, 회수 전력, 패드 발열 감소율을 계산한다.
  - **주행 애니메이션**: 계산 결과를 실제 시간 비율로 재생한다. 바퀴 회전, 브레이크 디스크 발열(마찰 일률의 상대 크기), 발전 전류, 배터리 누적 회수량, 제동력 화살표가 입력값에 따라 바뀐다.
- 모든 결과에 에너지 보존 검산(초기 운동에너지와 각 경로 에너지 합의 차이)을 표시한다.

## 사용법

`index.html` 하나로 동작한다. 브라우저에서 파일을 직접 열거나 GitHub Pages로 배포하면 된다.

## 계산 모형

- 기본 모드: *m* d*v*/d*t* = −(*F*<sub>fr</sub> + *P*(*v*)/*v*), *P*(*v*) = (*Kv*)<sup>2</sup>/(*R*+*r*) × (1 − tanh *x* / *x*), *x* = (*R*+*r*)/(4*Lf*)

고급 모드:

- 발전기: *ε* = *kω*, *I* = *ε*/(*R* + *r*), *τ* = *kI* (영구자석 직류 발전기 근사)
- 실험 모형: *J* d*ω*/d*t* = −*kI* − *τ*<sub>f</sub> − *bω*
- 실차 모형: *m* d*v*/d*t* = −(*F*<sub>gen</sub> + *F*<sub>fr</sub> + *F*<sub>air</sub> + *F*<sub>roll</sub>)
- 수치해법: 4차 룽게-쿠타법

기호의 뜻과 가정은 페이지 하단의 ‘계산 모형’ 절에 정리했다. 기본 입력값은 예시(가정)값이므로 실제 부품의 측정값으로 바꿔 넣어야 한다.
