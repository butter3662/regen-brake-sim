# 브레이크 회생발전 시뮬레이터

내연기관 자동차의 제동 에너지를 전자기유도로 회수하는 과정을 계산하는 웹 시뮬레이터이다. 에너지 하베스팅 자율탐구용으로 만들었다.

## 기능

- **기본 모드 (시뮬레이션 탭)**: 최종 설계안(쇳조각 원판 + 고정 U자 철심, 유도자형)으로 계산한다. 바퀴와 함께 도는 쇳조각 12개가 차체에 고정한 U자 철심 8개(A 4개, B 4개)의 틈을 메웠다 비웠다 한다.
  - 기본 발전 방식: **전력 변환기(스위치드 릴럭턴스)**. 계자 코일 없이 철심마다 코일 1개를 비대칭 하프브리지로 제어한다. 위치에 따라 바뀌는 인덕턴스로 코일 전압식을 수치 적분하고, 켜고 끄는 위치를 속력마다 최적화한다. 전류 상한 = min(철심 포화 전류, 스위치 전류 한계 *I*<sub>max</sub>), 기본 16회·149.2 A. 여자 에너지(사용)와 순 생산을 나눠 표시한다.
  - 비교용: **다이오드 정류 + 계자 코일**. 발전 코일의 네모파 기전력, RL 회로 평균 전력, 계자 소비 전력, 손익분기 속력, 순이득이 가장 큰 계자 전류·감은 수를 계산한다.
  - 변수: 제동 시작 속력 *v*<sub>0</sub>, 차량 질량 *m*, 마찰 브레이크 제동력 *F*<sub>fr</sub>, 코일 감은 수 *N*<sub>a</sub>, 철심 수 *n*, 다리 끝 길이 *h*, (다이오드) 계자 전류·감은 수, (전력 변환기) 스위치 전류 한계. 장치는 휠 바깥(차체 쪽)에 단다고 보고, 철심 배치가 타이어 반지름·지면 간격 조건을 지키는지 검사한다.
  - 결과: 주행 애니메이션, 누적 발전·사용·순 생산 에너지(휴대폰 3.85 V mAh 환산), 회수 효율(순 생산 ÷ 손실), 속력별 충전 전력, 제동 시작 속력별 발전량.
- **작동 원리 탭**: 흐름도, 쇳조각이 철심 A·B 사이를 지나가는 펼친 그림과 전류·자속 그래프 애니메이션, 단계별 원리, 에너지 분배.
- **3D 모형 탭**: WebGL(GPU, 멀티샘플 안티앨리어싱)로 그리고, WebGL이 없으면 자체 소프트웨어 렌더러로 그린다. 회전·확대, ‘U자 철심 확대’, 누적 에너지 생산, ‘작동 과정 보기’(켜기 → 붙잡기 → 끄기 슬로 모션과 회로 전류 경로). 두 발전 방식으로 바꿔 볼 수 있다.
- **세부 내용 탭**: 계산 조건, 기본값의 근거, 화면 읽는 법, 계산 방법, 장치 구성도·회로도(발전 방식에 따라 바뀜), 부품표.
- **예상 효과 탭**: 시내 주행(0 → 60 → 0 km/h, 3분 주기, 하루 20회) 연비 개선 추정과 테슬라 수준 회생제동(운동에너지의 70% 회수) 대조군 비교.
- **고급 모드** (스위치로 켜고 끔): 일반 영구자석 직류 발전기로 근사한 별개 모형.
  - **실험 모형 (회전 원판)**: 회전수 변화, 부하 전력, 에너지 분배, 부하 저항 *R*에 따른 회수 에너지 최적값.
  - **실차 모형 (내연기관차)**: 목표 감속도로 정지할 때 발전기·마찰 브레이크 제동력 분담, 회수 전력, 패드 발열 감소율, 주행 애니메이션, 에너지 보존 검산.
- 새 버전이 배포되면 쓰던 설정을 유지한 채 자동으로 새로고침한다. 페이지 맨 아래에 현재 버전을 표시한다.

## 사용법

`index.html` 하나로 동작한다. 브라우저에서 파일을 직접 열거나 GitHub Pages로 배포하면 된다.

## 계산 모형

- 기본 모드 공통: *m* d*v*/d*t* = −(*F*<sub>fr</sub> + *F*<sub>gen</sub>(*v*))
- 전력 변환기 방식: *v* = *Ri* + *L*(*θ*) d*i*/d*t* + *iω* d*L*/d*θ*, *T* = ½*i*<sup>2</sup> d*L*/d*θ*, 한 칸(쇳조각 하나)씩 수치 적분
- 다이오드 방식: *P*(*v*) = (*Kv*)<sup>2</sup>/(*R*+*r*) × (1 − tanh *x* / *x*), *x* = (*R*+*r*)/(4*Lf*), *F*<sub>gen</sub> = *P*/*v*

고급 모드:

- 발전기: *ε* = *kω*, *I* = *ε*/(*R* + *r*), *τ* = *kI* (영구자석 직류 발전기 근사)
- 실험 모형: *J* d*ω*/d*t* = −*kI* − *τ*<sub>f</sub> − *bω*
- 실차 모형: *m* d*v*/d*t* = −(*F*<sub>gen</sub> + *F*<sub>fr</sub> + *F*<sub>air</sub> + *F*<sub>roll</sub>)
- 수치해법: 4차 룽게-쿠타법

기호의 뜻과 가정은 ‘세부 내용’ 탭(기본 모드)과 페이지 하단 ‘계산 모형’ 절(고급 모드)에 정리했다. 기본 입력값은 예시(가정)값이므로 실제 부품의 측정값으로 바꿔 넣어야 한다.
