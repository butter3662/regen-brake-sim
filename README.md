# 브레이크 회생발전 시뮬레이터

내연기관 자동차의 제동 에너지를 전자기유도로 회수하는 과정을 계산하는 웹 시뮬레이터이다. 에너지 하베스팅 자율탐구용으로 만들었다.

## 기능

- **기본 모드**: 자기장 세기 *B*, 제동 시작 속력 *v*<sub>0</sub>, 차량 질량 *m*, 코일 감은 수 *N*, 코일 면적 *S*를 바꾸며 제동 중 발전량과 정지 거리를 계산한다. 마찰 브레이크(일정한 힘)와 전자기유도 제동(속력에 비례하는 힘)이 제동 시작부터 함께 작동한다. 값을 기준으로 저장해 두고 몇 배 차이인지 비교할 수 있고, 입력값에 따라 자동차 주행 애니메이션이 바뀐다. 영구자석과 전자석(계자 전류·감은 수·저항 입력, 소비 전력·순이득·손익분기 속력 계산) 중에서 고를 수 있다. 발전량은 에너지 보존으로 *E* = *R*/(*R*+*r*) × (½*mv*<sub>0</sub><sup>2</sup> − *F*<sub>fr</sub>*x*<sub>s</sub>)이다.
- **작동 원리·세부 구조 탭**: 흐름도, 회전 코일과 자기선속·기전력 그래프 애니메이션, 단계별 원리, 장치 구성도, 회로도, 부품표를 보여 준다.
- **고급 모드** (스위치로 켜고 끔): 아래 세 기능을 포함한다.
  - **실험 모형 (회전 원판)**: 소형 발전기를 회전 원판에 연결했을 때 회전수 변화, 부하 전력, 에너지 분배를 계산하고, 부하 저항 *R*에 따른 회수 에너지 곡선에서 최적값을 찾는다.
  - **실차 모형 (내연기관차)**: 별도 발전기를 장착한 차량이 목표 감속도로 정지할 때 발전기와 마찰 브레이크의 제동력 분담, 회수 전력, 패드 발열 감소율을 계산한다.
  - **주행 애니메이션**: 계산 결과를 실제 시간 비율로 재생한다. 바퀴 회전, 브레이크 디스크 발열(마찰 일률의 상대 크기), 발전 전류, 배터리 누적 회수량, 제동력 화살표가 입력값에 따라 바뀐다.
- 모든 결과에 에너지 보존 검산(초기 운동에너지와 각 경로 에너지 합의 차이)을 표시한다.

## 사용법

`index.html` 하나로 동작한다. 브라우저에서 파일을 직접 열거나 GitHub Pages로 배포하면 된다.

## 계산 모형

- 발전기: *ε* = *kω*, *I* = *ε*/(*R* + *r*), *τ* = *kI* (영구자석 직류 발전기 근사)
- 실험 모형: *J* d*ω*/d*t* = −*kI* − *τ*<sub>f</sub> − *bω*
- 실차 모형: *m* d*v*/d*t* = −(*F*<sub>gen</sub> + *F*<sub>fr</sub> + *F*<sub>air</sub> + *F*<sub>roll</sub>)
- 수치해법: 4차 룽게-쿠타법

기호의 뜻과 가정은 페이지 하단의 ‘계산 모형’ 절에 정리했다. 기본 입력값은 예시(가정)값이므로 실제 부품의 측정값으로 바꿔 넣어야 한다.
